# Etiqueta Fácil

Programa grátis para Windows que imprime as etiquetas do Mercado Livre e da Shopee direto na impressora térmica (Zebra, Elgin, Xprinter, Knup e Argox), sem converter para PDF.

**[Baixar a versão mais recente](https://github.com/Carlosbk74/etiqueta-facil/releases/latest)** · [Página do programa](https://www.backsistemas.com.br/ferramentas/etiqueta-facil)

Este repositório só distribui o instalador. O Etiqueta Fácil é software proprietário da BackSistemas, gratuito para uso.

## Aviso do Windows na instalação

Ao abrir o instalador, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.
